# Noctune

**Превращай новеллы в аудиокниги.**

Noctune — мобильное приложение для озвучивания новелл с помощью ИИ. Пользователь загружает свои файлы, выбирает голос и слушает готовые аудиокниги где угодно, даже без интернета.

## Возможности MVP

- Импорт книг в форматах EPUB и TXT.
- Извлечение глав и генерация речи фрагментами.
- Выбор голоса для озвучивания.
- Отслеживание прогресса и восстановление прерванной генерации.
- Скачивание аудио для офлайн-прослушивания.
- Сохранение позиции воспроизведения.

## Технологии

- **Мобильное приложение:** React Native, Expo, TypeScript.
- **Backend:** Node.js, Express, TypeScript.
- **База данных:** PostgreSQL.
- **Синтез речи:** Kokoro-82M или подходящая русская адаптация.
- **Инфраструктура:** домашний ПК для локальной генерации, VPS для безопасного удалённого доступа.

## Архитектура

Мобильное приложение взаимодействует с backend через публичный HTTPS-адрес на VPS. Backend управляет библиотекой и задачами генерации, а домашний ПК выполняет синтез речи.

Готовые аудиофайлы можно скачать на телефон и слушать офлайн.

## Статус проекта

**Проектирование и прототипирование.** Объём MVP определён. Модель синтеза речи и способ её запуска ещё проверяются.

## План разработки

1. Проверить качество русской озвучки и склейки аудиофрагментов.
2. Спроектировать схему БД и API-контракт.
3. Реализовать конвейер генерации аудио.
4. Разработать мобильную библиотеку и плеер.
5. Настроить безопасный удалённый доступ и офлайн-прослушивание.
